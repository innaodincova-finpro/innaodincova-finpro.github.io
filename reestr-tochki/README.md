# Отдельная установка Реестра

Адрес /reestr-tochki/ находится вне прежней области /tochka-dnya/ установленной «Точки дня». Здесь собственные manifest, название, start_url, scope и service worker. Основной сайт в корне не изменён.

Интерфейс Реестра теперь также размещён здесь. API, авторизация, registry.js и изображения используются из tochka-dnya. При изменении разметки Реестра обновлять index.html этого каталога вместе с reestr.html основного репозитория; обработчики и бизнес-логика остаются общими. Service worker обновляет общие скрипты по сети и не кэширует ответы Supabase.

CI проверяет имя и непересекающийся адрес, браузерный интерфейс на 320/390/430/1280 px, безопасные отступы, диалог приглашения и обработчик кнопки установки. Установка средствами ОС в CI не проверяется. На компьютере пользователя старый ярлык «Точки дня» удалять не нужно: новый Реестр устанавливается с нового адреса.
